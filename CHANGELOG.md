# Changelog

## Public GitHub source release

- Established `VICE68kRGB` as the clean Future Retro Fusion VICE 3.1 AmigaOS
  source repository.
- Preserved upstream VICE `COPYING`, copyright headers and file-specific licence
  notices.
- Documented repository licensing as GPL-2.0-or-later where applicable.
- Explicitly licensed original FRF contributions on the same terms as modified
  VICE files.
- Added `FRF_CONTRIBUTIONS.md`, `NOTICE.md`, `LICENSE.md` and build guidance.
- Added a stable-source publication gate requiring V37 and rejecting V38.
- Removed local build products, recovery backups, personal paths, ROM/media
  payloads and snapshots from the public staging tree.
